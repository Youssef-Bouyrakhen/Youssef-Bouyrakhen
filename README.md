### 🛰️ What I'm building right now

**[Job Radar](https://github.com/Youssef-Bouyrakhen/job-radar)** — I got tired of refreshing job boards, so I built a bot that doesn't sleep.

- Python + FastAPI backend, own dashboard, SQLite
- Runs **24/7 on a Linux cloud server** I set up and maintain myself (Linode/Akamai)
- Scans job portals + ~90 watched company pages **every hour**, around Darmstadt/Frankfurt
- Scores every job with a free LLM, using prompts I wrote and kept rewriting until the ratings made sense
- Pushes alerts straight to Telegram
- Covers 19 towns + Frankfurt district by district — because "Griesheim" is both a town *and* a Frankfurt neighborhood, and yes, that bit me once

It's the project that taught me more about real systems — uptime, rate limits, logs, debugging at 3am — than any single course did.
